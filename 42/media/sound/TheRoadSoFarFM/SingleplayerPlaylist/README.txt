No action is needed for normal use: the mod plays its default playlist.

ONLY CUSTOMIZE THIS FOLDER IF YOU WANT A DIFFERENT SINGLEPLAYER PLAYLIST!

Run 42/tools/Build-SingleplayerPlaylist.bat once to initialize it with the
station's default songs. Then add or remove MP3 or OGG files here and run
the BAT again.

Restart Project Zomboid after regenerating so it loads the sound definitions.
