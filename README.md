# The-Road-So-Far-FM
The Road So Far FM is a Supernatural-inspired music mod for Project Zomboid Build 42. It adds a custom radio station at 99.6 MHz for compatible radios and vehicles, plus Dean's Top 13 Zepp Traxx, a playable cassette with 13 sequential tracks. 

The cassette displays each track title during playback. Radio and cassette sounds can attract zombies according to device volume and the mod's Sandbox setting, which can disable this attraction. Portable devices with headphones on never attract zombies, as in the base game.
